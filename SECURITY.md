# Security and privacy

The application has no account system, remote service, analytics, or telemetry. The published demo is served by GitHub Pages, whose hosting service receives ordinary web requests. Do not place participant names, contact details, health information, or operational records into examples or issue reports.

For a suspected vulnerability, contact **gabrieldemetrioslafis@usp.br** with a minimal synthetic reproduction. Please avoid posting sensitive details publicly before a fix can be assessed. Version 1.x is the current maintenance line; response times are not guaranteed.
