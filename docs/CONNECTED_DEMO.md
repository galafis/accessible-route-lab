# A connected demonstration / Uma demonstração conectada

## English

Compare a grid route here, then evaluate destinations, personal passage preferences and proposed venue improvements in the Python atlas.

The narrow-passage example demonstrates footprint inflation. The atlas library example then shows 5/6 reachable preference/destination pairs, becoming 6/6 with explicitly selected hypothetical changes. These are complementary models; their scenario formats are different and are not automatically converted.

1. Run this repository's documented example and identify its main assumption.
2. Open [Venue Access Atlas](https://github.com/galafis/go2-pro-accessible-venue-audit) and follow its bilingual installation guide.
3. Reproduce the committed scenario, change one assumption and explain the resulting difference.
4. Keep the report and exact input together. Describe what still needs a physical measurement or participant review.

The intended study context includes Unitree Go2 PRO. These demonstrations use synthetic data and do not command a robot or expose a private implementation.

## Português

Compare aqui um percurso em grade; depois avalie destinos, preferências de passagem e melhorias propostas do espaço no atlas em Python.

O exemplo de passagem estreita demonstra a expansão dos obstáculos conforme o espaço ocupado. O exemplo da biblioteca no atlas mostra então 5/6 pares de preferência/destino alcançáveis, passando a 6/6 com mudanças hipotéticas selecionadas explicitamente. São modelos complementares; os formatos dos cenários são diferentes e não são convertidos automaticamente.

1. Execute o exemplo documentado deste repositório e identifique sua principal hipótese.
2. Abra [Venue Access Atlas](https://github.com/galafis/go2-pro-accessible-venue-audit) e siga o guia bilíngue de instalação.
3. Reproduza o cenário publicado, altere uma hipótese e explique a diferença resultante.
4. Guarde relatório e entrada exata juntos. Descreva o que ainda precisa de medição física ou revisão com participantes.

O contexto pretendido de estudo inclui Unitree Go2 PRO. As demonstrações usam dados sintéticos, não comandam um robô e não expõem uma implementação privada.
