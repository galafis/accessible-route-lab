## English

## 1.0.0 — 2026-09-10

Initial public software release of Accessible Route Lab.

- Deterministic route planning: Four-connected A\* with Manhattan distance, stable tie-breaking, and configurable rough-surface cost.
- Clearance experiments: Obstacle inflation using a conservative square envelope, including map-edge clearance.
- Editable maps: Place obstacles, rough surfaces, start points, and destinations using a pointer or keyboard.
- Inspectable results: Distance, direction changes, weighted cost, written compass directions, and step-by-step replay.
- Portable experiments: Versioned JSON import/export, strict input validation, and three built-in scenarios.

Includes behavioral tests, a static browser demo, versioned examples, and architecture and project guides.

## Português

### 1.0.0 — 2026-09-10

Primeira versão pública de Accessible Route Lab. Planejamento A\* ortogonal com desempate determinístico, custo configurável de terreno, envelope quadrado conservador e bordas do mapa. Edição por ponteiro ou teclado, distância, curvas, custo, direções e reprodução passo a passo. Importação/exportação JSON validada e três cenários integrados.

Inclui testes de comportamento, demonstração estática, exemplos versionados e guias de arquitetura e projeto.
